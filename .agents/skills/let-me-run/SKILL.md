# Let Me Run

ユーザー自身が手元の環境で実行し、動作を確認できる状態にする。

## Context

- ユーザーはプロジェクトのリポジトリルートにいるものとする。
- 提示するコマンドは、リポジトリルートからの実行を前提とする。

## Instructions

- 現在の実装状況と実行に必要な前提条件を確認する。
- 依存関係の不足やビルドエラーなど、実行を妨げる問題は必要最小限の範囲で解消し、必要なセットアップやビルドを済ませる。
- 既存の実行環境や設定を不必要に変更しない。
- 環境変数や認証情報など、ユーザー操作が必要な前提条件は推測で埋めない。
- AI側で起動確認を行った場合、確認用プロセスは終了前に必ず停止しておく。
- 提示するコマンドにはパイプ（`|`）、連結演算子（`&&`、`;`）、バックグラウンド実行（`&`）を使わず、1コマンド1行にする。
- AI側でテストや起動確認を行った場合でも、ユーザー向けの実行コマンドや確認手順の提示を省略しない。

## Output

以下の要素を簡潔に提示する（該当しない項目は省略する）。

- AI側で実施した準備や修正の概要
- ユーザー側で事前に必要な対応（環境変数・認証情報・外部ツールなど）
- 実行コマンド（複数プロセス同時起動時は役割と起動順を明記し、ターミナル単位で分離）
- アクセス先URL（Webアプリケーションの場合）
- 動作確認の操作手順と、それぞれの期待される結果

## Completion Criteria

ユーザーが追加の調査や準備を必要とせず、提示されたコマンドを実行するだけで直ちに動作確認を開始できること。
